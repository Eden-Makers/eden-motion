Inside

A studio pipeline, not a template

Every step is plain JSON in a project folder, so an agent or a person can stop anywhere, change it and carry on.

0.92 to 0.02 px

Text judder under the camera push, measured on the render

120 ms

How far a cut may move to land on the music's beat

31

Scenes in four styles, plus three Blender templates

Product films

An HTML twin of your UI instead of a screen recording, CG device shots in Blender, b-roll close-ups, a lens finish only on the fast moves and a 9:16 cut that keeps the composition.

Real 3D from Blender

blender: props render headless plates. layers-3d puts screenshots into real space for depth of field, rack focus and parallax.

True motion blur

Time stretches where things move fast, sub-frames are captured and averaged through a 180 degree shutter. Smear only where it belongs.

Sound on the beat

Voice, music, ambience and four SFX layers as stems. sync snaps cuts to the beat, one-shots land a frame early and pan with what makes them.

Measured, not eyeballed

measure steps through every frame: reading time per line, text cut by the frame, ease tails that freeze, glyph judder.

A director loop

Contact sheets, a phone-size test, frame strips around every cut and a calibrated rubric. It never ships the first render.

Rebuild any reference

ref measures a film, compare puts yours next to it with SSIM, critique --against scores both the same way.

Any frame

16:9, 4:5, 1:1 and 9:16. Portrait films are laid out on a larger stage and scaled down, so type stays supersampled.

Install

Two commands, then ask for a film

The agent checks your tools, installs what is missing and asks for API keys in a masked prompt in your own terminal, never in the chat.

In Claude Code

/plugin marketplace add Eden-Makers/eden-motion
/plugin install eden-motion@eden-motion
> set up eden-motion
> make a 40 second launch film for Linear, 4:5

From a terminal

# macOS, Node 20+, ffmpeg, Chrome
git clone https://github.com/Eden-Makers/eden-motion
cd eden-motion && ./install.sh
eden-motion setup
eden-motion new "Attio" --url https://attio.com --format 4:5

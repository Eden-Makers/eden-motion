# Higgsfield Style Bible

High-energy AI-native product launch and agent-demo style modeled after Higgsfield's viral X promos ("Higgsfield MCP x Claude Fable 5.1", "Higgsfield {API}", "Higgsfield MCP x Claude Opus 5.5"): crisp technical off-white paper, extreme macro-to-wide-to-macro UI choreography, coral/lime/magenta digital pixel ripples, tactile hot-tail agent typing, punch-in button shockwaves, and full-bleed AI/3D payoff shots.

---

## 1. Identity & When to Use

- **Core identity**: The definitive "agentic AI product demo" film language. Bridges crisp 2D interactive UI storytelling (`0:04-0:08` prompt -> send -> analyzing -> preview grid) with jaw-dropping generative AI or 3D proof payoffs, held together by digital pixel/mosaic transitions, punch-in hard cuts, and "hold, sprint, land" pacing.
- **Best fit**:
  - 20-60 s AI product launches, MCP / Claude / agent workflow demos, API endpoint announcements, and generative creative tool promos.
  - Music + SFX only (zero voiceover): the UI prompts, agent status lines, and micro-captions carry 100% of the narrative cleanly even when muted on X.
  - Co-brand launches where warm partner accents (e.g. Claude terracotta coral `#d3725c`) meet technical Higgsfield lime (`#d4ff19`) or electric magenta (`#df167f`).

## 2. What This Style IS NOT

- **NOT a slow dark-mode obsidian keynote**: Predominantly bright crisp paper (`mean luma 147.9-165.6`, `darkShare 25-26%`), saving dark worlds for brief HUD technical interludes or full-bleed AI payoff footage.
- **NOT polite Gaussian blur corporate explainers**: Elements arrive through **digital states** (coral/lime pixel mosaic ripples, bitmap-to-vector type resolves, thermal duotone 4-frame settles, chromatic RGB-split barrel whips) rather than soft Burnwe fog dissolves.
- **NOT uniform slide-deck cuts**: Explicitly structured as **"hold, sprint, land"** (`shotCV 0.78-0.87`), contrasting `1.0-2.5 s` crisp reading holds against `3-8 frame` (`0.10-0.27 s`) kinetic transitions and `0.5-1.3 s` punch-in beats.
- **NOT forced 38-degree tilted UI screenshots**: Prompt cards, chat threads, and agent status views stay **100% flat 2D (`rotateX=0, rotateY=0`)** and derive kinetic drama from `2.18x -> 1.00x -> 3.45x` magnification choreography.

## 3. Color & Contrast Rules

- **Two signature palette modes (pick ONE per film)**:
  1. **Co-Brand Agent Paper (`higgsfield-mcp.mp4` / Opus 5.5)**: Neutral soft paper canvas `#f0f0f0` (`luma 240`), borderless floating composer card `#fefefe` (`luma 254`, strictly **+14 luma delta, zero dark border**), charcoal ink `#161616`, user thread bubble `#e1e1e2`, primary accent Claude terracotta coral `#d3725c` (button, hot-tail text, mosaic ripple `#f9c0b0`), secondary Higgsfield action lime `#d4ff19` (only on Higgsfield-specific generation/3D states).
  2. **Pure API Technical Grid (`Higgsfield {API}`)**: Crisp white technical grid `#fcfcfc` with `1.5 px` `#1a1a1a` hairlines, `#111111` ink, electric magenta `#df167f` pills/type, acid lime `#d4ff19` highlights/floods, and a single brief dark lime HUD interlude (`#131813` bg, `#b6f03a` neon vector lines).
- **Controlled saturation & contrast**: Measured frame `contrast` **`33.8-43.4`**, `saturation` **`0.200-0.248`**, `clean_negative_space` **`68.6%`**. Even with neon lime or coral accents, 70%+ of every UI frame stays calm light neutral paper so the bright interactive element pops immediately.
- **Polarity & thermal transitions**: `polarityFlips 0.25-0.36`. Incoming full-bleed AI shots may open with a `2-4 frame` thermal duotone settle (`magenta/lime` -> natural color) or `3-frame` overexposure white bloom (`+2/+4/+2 stops`) before snapping clean.

## 4. Typography Rules

- **Three coordinated voices**:
  1. **UI & Agent Stream Sans**: Clean geometric sans (`Inter`, `DM Sans`, `Geist`, Regular/Medium `400-500`), `#161616` ink with `#6b6b6b` secondary metadata (`Fable 5.1`, `PDF`). Never bold-heavy inside chat cards.
  2. **Squared Tech Display (API / Promo beats)**: Bold squared grotesk (`Space Grotesk`, `Neue Machina`, `Geist` Bold `700`), all caps, tracking `-0.02em`, line-height `0.95`, cap height `5-7%` of frame.
  3. **Transient Bitmap / Monospace Micro**: `10-12 px` uppercase monospace gutter coordinates/measurements (`Measuring height: ~34 ft`, `BUILDING YOUR 3D SCENE FROM SCRATCH`) + optional `3-5 frame` bitmap/pixel-glyph resolve on headline entry.
- **Hot-tail prompt & agent typing (measured on `higgsfield-mcp.mp4` 4.26-5.33 s)**:
  - Speed: **`45-55 chars/s`** (`~1.7-1.8 chars/frame` at 30 fps) so prompts feel snappy and alive, never sluggish.
  - Hot tail: newest **`8-14 characters`** glow in `#d3725c` coral (or `#d4ff19` lime / `#df167f` magenta) and cool smoothly to `#161616` charcoal over `~8 frames` (`0.27 s`).
  - Always follow typing with a **`0.85-1.00 s` calm reading hold** (`diff < 0.8`) before punching in!

## 6. Signature Moves & Content Fit

- **Macro -> Wide -> Macro UI Sandwich (`macro-ui`, `answer-stream`)**: The exact `higgsfield-mcp.mp4` `0:04-0:08` grammar: `2.18x` macro thumbnail arrival + coral mosaic pixel ripple -> `3 f` whip zoom-out -> `1.0 s` reading hold (`+7.3%/s` push) -> `3.45x` hard punch-in on send button -> concentric coral shockwave (`8 f`) -> RGB barrel whip (`5 f`) -> `1 f` `#f0f0f0` clean reset -> thread snap-in (`Analyzing image...`).
- **Agent status stream + spinning brand glyph (`terminal`, `answer-stream`)**: Left-aligned spinning coral asterisk or lime Higgsfield mark + 1-2 lines of hot-tail status text cooling coral -> charcoal, swapping via `6 f` focus blur.
- **2x2 fly-from-depth AI preview grid**: Four generative variants pop in from `scale 0.2 + 15 px blur` over `4-5 f` (`0.15 s` stagger), followed by a crisp grey selection card highlighting the winner (`higgsfield-mcp 19-22 s`).
- **Condition / spatial measurement HUD overlay (`micro-ticker`)**: Hard-cut `2x` crops over real/AI footage with stroke-drawn neon lime/coral measurement boxes, counting `%` or `~34 ft` reference callouts (`higgsfield-mcp 10 s`, `Opus 5.5 16-20 s`).
- **Technical grid reflow (`shader-grid`)**: Crisp `1.5 px` hairline cells sliding (`0.5 s expo.inOut`) to re-partition media, stripe-gradient fills, and bitmap headlines (`Higgsfield {API}`).
- **Quiet tiny-caps end card**: Plain paper or clean hero-payoff frame with tiny tracked uppercase CTA (`TRY ... ON CLAUDE WITH HIGGSFIELD MCP`), held `1.8-2.2 s` with zero sting SFX.

## 9. Sound & SFX Grammar

- **Click = The Drop**: The single most important audio rule in Higgsfield films. Place the music track's main bass drop or energetic beat entry **exactly on the macro send-button press (`+/- 80 ms`)** (`higgsfield-mcp 6.60 s`, `Higgsfield {API} 5.50 s`).
- **Pre-Reveal Audio Breath**: Automatically duck music RMS by `-6 to -9 dB` for `0.30-0.50 s` leading into every major reveal (3D assembly, 2x2 preview grid, hero payoff), returning cleanly to `0 dB` on the reveal frame.
- **Digital Micro-SFX Palette**: Crisp tactile keyboard ticks on hot-tail typing (capped `<= 30/s`), granular digital sparkle on coral/lime mosaic ripples, resonant punchy click + low whoosh on send-button shockwave, tight air-whip on `3 f` zoom-outs, subtle mechanical ratchet clicks on 3D exploded assemblies.
- **Quiet End Card**: Zero logo slam SFX on the final frame; let the track's tail or hero payoff decay naturally under the static tiny-caps CTA.

## 10. Anti-Slop Traps & Fixes

| Anti-Slop Trap | Why It Breaks `higgsfield` | Concrete Fix |
|---|---|---|
| **Zero reading hold after typing** | Viewer cannot read the prompt before the cut slams in | Enforce `0.85-1.00 s` calm hold (`diff < 0.8`) with `+7%/s` silent push-in after typing completes |
| **Harsh black borders on light composer cards** | Destroys the airy `#f0f0f0` / `#fefefe` Apple/Claude craft | Use `#f0f0f0` ground + `#fefefe` card (+14 luma delta), `border: none`, soft ambient shadow `0 20px 50px rgba(0,0,0,0.06)` |
| **Forgetting the 1-frame clean paper breath** | Outgoing RGB whip collides muddily with incoming chat thread | Insert a `1 f` (`33 ms`) solid `#f0f0f0` reset frame (`7.067 s`) between whip-out and snap-in |
| **Overusing flash frames (> 1 per 3 s)** | Turns crisp digital punctuation into cheap seizure spam | Hard-cap flash/overexpose events to major section transitions only |
| **AI-generating the chat UI** | Produces garbled text and melting buttons | Always build prompts, buttons, and agent streams in crisp 2D HyperFrames HTML/GSAP; reserve AI strictly for the visual outputs inside/after the UI |
